# Notepadz v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Notepadz, a full-window, tabbed, offline-first browser notepad with session restore, stored only in IndexedDB, deployed to GitHub Pages as a PWA.

**Architecture:** A Vite + React 19 SPA. A single Zustand store holds notes, the session, settings and UI state. A persistence bridge mirrors the store into Dexie (IndexedDB) with debounced writes that flush on page hide. CodeMirror 6 is the editor. One command registry drives the shortcuts, the `cmdk` palette and the menus. A BroadcastChannel keeps windows in sync, with compare-and-set saves that turn a lost race into a "conflict copy" note.

**Tech Stack:** Vite, React 19, TypeScript (strict), Zustand, Dexie + dexie-react-hooks, CodeMirror 6 (`@uiw/react-codemirror`, `@codemirror/language-data`, `@codemirror/legacy-modes`), Tailwind CSS v4, Radix UI primitives, cmdk, @dnd-kit, lucide-react, react-markdown + remark-gfm + rehype-sanitize, vite-plugin-pwa, Vitest + Testing Library + fake-indexeddb, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-16-notepadz-design.md`. Read it before starting any task. Section references (§) point there.

## Global Constraints

- Node 24, npm. Install the latest stable version of each library listed above at scaffold time, and commit `package-lock.json`.
- TypeScript `strict: true`. No `any` in exported signatures.
- Vite `base: '/notepadz/'` for production builds, `/` for dev.
- No network requests carry note content. No analytics. Fonts (Inter, JetBrains Mono) are self-hosted via `@fontsource-variable/*`.
- Debounce: content writes **300ms**, session/view-state writes **1000ms**. Flush on `visibilitychange→hidden`, `pagehide`, tab switch and note close.
- The closed-tab stack holds at most **20**. Trash keeps notes for **30 days**. The backup reminder default is **7 days**.
- Auto-title: the first non-empty line, trimmed, cut to **40** characters, falling back to `"Untitled"`.
- Large-document guard: above **2,000,000** characters, syntax highlighting is turned off.
- Shortcuts follow §6.5 exactly: `Mod2` = `Ctrl+Alt` on macOS and `Alt` on Windows/Linux, matched on `KeyboardEvent.code`. On Windows/Linux, events with both `ctrlKey` and `altKey` (AltGr) never match a Mod2 shortcut.
- Theme tokens are CSS variables. Calm accent: dark `#7c9cff`, light `#4f6fff`. Respect `prefers-reduced-motion`.
- Commits: Conventional Commits, one logical change each. Never "wip". The `.superpowers/` folder stays git-ignored.

## Review Focus

1. **Reload or closing the tab within 300ms of typing:** the last keystrokes must be present after reload. Test: Task 8 `flushes pending content on pagehide`, Task 17 e2e `type-then-reload`.
2. **Pasting a 10MB log:** the UI stays responsive, highlighting turns off and typing still works. Test: Task 11 `isLargeDoc threshold`, Task 17 e2e `big-paste`.
3. **Importing a corrupt or foreign JSON file:** a clear error is shown and no existing data changes. Test: Task 14 `parseBackup rejects foreign json`, `import of invalid file leaves db unchanged`.
4. **IndexedDB unavailable or quota exceeded:** the app still opens and edits work in memory, the status shows `⚠ Not saved` and Export is offered. Test: Task 8 `write failure sets saveStatus error and keeps text`.
5. **Non-US layout / AltGr / Mac Option typing `[ ] | @`:** never swallowed by a shortcut. Test: Task 10 `AltGr does not match Mod2`, `mac Option alone does not match Mod2`.

```ts
createDebouncedWriter<V>(write: (key: string, v: V) => Promise<void>, delayMs: number):
  { schedule(key: string, v: V): void; flush(): Promise<void>; hasPending(key?: string): boolean; cancel(key: string): void }
startPersistence(store: StoreApi<AppStore>, db: NotepadzDB, opts?: { contentDelay?: number; sessionDelay?: number; target?: Window }):
  { flush(): Promise<void>; stop(): void; onConflict(cb: (local: Note, current: Note) => void): void; hasPendingFor(id: string): boolean }
loadInitialState(db: NotepadzDB, now: number): Promise<Partial<AppState>>

toast(msg: string, opts?: { action?: { label: string; run(): void }; tone?: 'info'|'warn'|'error'; durationMs?: number }): void
```
  - The persistence bridge subscribes to the store:
    - Changed notes are written through `saveNote` with the last-known `rev`. It tracks `knownRev[id]` in memory and updates the store's `rev` on success.
    - The session and settings go through `putKv` (1000ms).
    - It flushes on `visibilitychange` (hidden), `pagehide`, active-tab change and note close.
    - A write rejection calls `setSaveStatus('error', message)`, keeps the store text, and retries with exponential backoff capped at 10s. The first failure shows a toast with an "Export now" action. Before Task 14 lands, that action opens Settings.
    - A CAS conflict calls the `onConflict` callbacks. The default handler is added in Task 15. Until then, log the conflict and reload the current copy.
  - `loadInitialState`:
    - Merges settings.
    - Purges expired trash.
    - Drops session ids whose notes are missing or trashed.
    - Appends pinned notes that aren't open.
    - Ensures at least one tab exists: if `meta.welcomeShown` is false, it creates the Welcome note and sets the flag. Otherwise it creates an empty note.
  - If `openDb` or `loadAll` throws (IndexedDB unavailable), it returns in-memory defaults, and the bridge stays disabled with `saveStatus: 'error'` and the message "Storage unavailable — changes won't persist".
